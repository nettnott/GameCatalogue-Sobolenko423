# УП.01.01 — Каталог компьютерных игр
### Соболенко А.Р. 4ИСИП-423

WPF-приложение (.NET Framework, C#) для ведения каталога компьютерных игр. База данных — Microsoft SQL Server, доступ к данным — ADO.NET Entity Framework (Database First) через класс Core.

### Функции:
- Авторизация с разграничением ролей (Пользователь, Администратор).
- Капча после трёх неверных попыток входа.
- Регистрация с проверкой данных, хэширование паролей (SHA-1).
- Смена пароля для авторизованных пользователей.
- Пользователь: просмотр каталога игр, поиск, фильтрация по категориям/жанрам, сортировка.
- Администратор: просмотр всех игр, поиск, фильтрация, сортировка, добавление, редактирование, удаление записей.
- Диаграммы (страница DiagramsPage): построение графиков и диаграмм разных видов на основе данных из БД.
- Экспорт отчётов в Microsoft Word (.docx), PDF и Microsoft Excel (.xlsx).
- Два стиля оформления (светлая тема LightDictionary.xaml и киберпанк-тема CyberpunkDictionary.xaml).

### Структура решения
db/ — скрипт создания и заполнения базы данных (DB_Sobolenko_GameCatalogue.sql).

res/ — ресурсы приложения (иконки icon.ico, icon.jpg).

Pages/ — страницы приложения:

AccountPage — профиль пользователя.

LoginPage, RegisterPage, ChangePassPage — авторизация, регистрация и смена пароля.

CataloguePage — просмотр каталога.

AdminPage — страница администратора со ссылками на страницы для управления.

AddGamePage, AddCategoryPage, AddUserPage — страницы для добавления данных в БД или их редактирования.

UsersTabPage, CategoryTabPage, GamesTabPage — данные из БД с возможностью редактирования.

DiagramsPage — статистика и графики.

Core.cs — работа с базой данных (контекст EF).

Lists.cs — статический класс для хранения текущего пользователя и списков, полученных из БД (для привязки данных).

LightDictionary.xaml, CyberpunkDictionary.xaml — словари стилей оформления.

### Запуск
Выполнить скрипт db/DB_Sobolenko_GameCatalogue.sql в SQL Server Management Studio.
При необходимости изменить имя сервера в строке подключения в App.config.
Открыть GameCatalogue.sln в Visual Studio 2022 и запустить (F5).
